# Project Template [![Copier](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/copier-org/copier/master/img/badge/badge-black.json)](https://github.com/copier-org/copier)

This is a [Copier](https://copier.readthedocs.io/en/stable) template for my projects. To use the template, run the following commands:

```bash
# install copier
uv tool install copier

# use the template
copier copy gh:georglauterbach/template.git '<PROJECT NAME>'

# update a project
copier update gh:georglauterbach/template.git
```
